# Art V3 — Approval Gate 1

These three review sheets define the proposed **Realistic Eastern Dark Fantasy
Pixel Art** direction before animation production begins.

## Authoritative references

- **Player:** the user-supplied elite Southern Song veteran reference: black
  chainmail/lamellar armour, dark red cloth, shield, saber, and heavy boots.
- **Gate Warden:** the user-supplied mounted armoured commander reference. This
  review direction treats the rider and barded horse together as the Boss
  silhouette.

The Ghost Melee, Ghost Archer, and Corpse Beast were designed to share those
references' realistic anatomy, historical material language, cold moonlight,
surface wear, palette, and pixel density.

## Files

- `character_lineup.png` — full-colour material, silhouette, and world-cohesion
  approval sheet.
- `silhouette_test.png` — solid-form readability check with all five subjects
  on one ground plane.
- `scale_reference.png` — technical grid showing the declared 100%, 105%, 108%,
  130%, and 240% hierarchy.

## Approval boundary

No animation sheets, gameplay assets, Godot resources, collision settings, or
combat timing were changed in this deliverable. Animation production begins
only after this lineup is approved.

Generated with the built-in image generation workflow using the two supplied
screenshots as visual references. The character-lineup prompt established the
design; the silhouette sheet derived its contours from that lineup; the scale
sheet was a high-fidelity edit of the approved lineup with only the technical
background and exact scale labels added.
